# Reference documents

Only the (public-domain) US patents are stored in this repository. The papers and datasheets below
are copyrighted by their publishers; download them from the links into the folders shown, which are
git-ignored. Some vendor sites block scripted downloads, so use a browser.

## Patents (`patents/`, included)

- US 3,714,462 - Blackmer, *Multiplier circuits* (1973): the original log/antilog gain cell
- US 4,234,804 - *Signal correction for electrical gain control systems* (1980)
- US 4,403,199 - Blackmer, *Gain control systems* (1983)
- US 4,471,320 - *Voltage controlled element* (1984)
